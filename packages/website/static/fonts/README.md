The woff2 files in this folder are the latin subsets of Sora, IBM Plex Sans and IBM Plex Mono, copied from the `@fontsource/*` packages so that the site serves its fonts itself.
All three families are licensed under the SIL Open Font License 1.1; see the `LICENSE-<family>.txt` files next to them.
Run `pnpm --filter website sync:fonts` to refresh them after upgrading the Fontsource packages.
